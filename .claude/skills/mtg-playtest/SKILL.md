# MTG テストプレイ（紙モデル）

`scripts/table.py` は**紙のテーブル**だけを持つ。カード、各領域、カウンター、ダメージ用ダイス、ライフパッド、マナ・ダイス、マーカー、付箋、メモ帳、ターンのトラッカー、乱数。どれもルールを知らない。

**プレイヤーが頭で行うことは、すべてAIが行う。** ターンを進める、優先権を回す、コストを払う、解決する、SBAを確かめる、誘発に気づく、P/Tを計算する、付箋を外す。スクリプトは何も自動で進めないし、ルール違反でも止めない。止まるのは物理的に不可能な操作（存在しないカード、負のカウンター、実在のカードを消す、見えない情報を見る）だけ。

設計の背景は [design/paper-model.md](../../../design/paper-model.md)。

## 始め方

プロジェクト直下から実行する（カードキャッシュ `cards/` と登録デッキ `decks/` は相対パス）。

```bash
T=.claude/skills/mtg-playtest/scripts/table.py
export MTG_STATE=playtest/20260926-1500-piza-goldfish/g01.json   # 状態ファイル。以後 --state を省ける
python $T init --deck1 piza --deck2 jund-sacrifice --seed 101 --first P1
python $T init --deck1 piza --goldfish --seed 101                 # 一人回し
```

- `--deck1`/`--deck2` は登録名（`decks/`）かデッキリストのパス。足りないカード情報は Scryfall から取得し、取れなければ保存せずに止まる。
- `init` が方針文書（`decklists/strategy/<登録名>.md`）のパスを出したら、最初のプレイ判断より前に読む。
- 保存先は `playtest/<YYYYMMDD-HHMM>-<内容>/g01.json`。1ゲーム1ファイル。`playtest/` は Git 管理外。
- 初手は `draw P1 7` と `draw P2 7`。マリガンは `mulligan P1`（手札を戻してシャッフルし7枚引く）→ ボトムに送るカードを `move <oid> library --bottom`。

操作の構文は [references/commands.md](references/commands.md)。不明な引数は `table.py <コマンド> -h`。

## 1手 = 1回の `run`

意味のあるひとまとまり（土地を置いて呪文を唱える、1つの呪文を解決する、など）を `run -` に標準入力で渡す。**全行が成功したときだけ1回保存**し、途中で止まれば何も適用しない。`undo` はこの単位で戻る。

```bash
python $T run - <<'EOF'
move 101 battlefield
tap 101
mana P1 add G
mana P1 pay G
move 55 stack
say "P1: 《ラノワールのエルフ》を唱える。P2は応答なし"
move 55 battlefield
EOF
```

- 結果を見てから次を決めるもの（ドロー、`look`、`search`、ダイス、相手の選択）の直後で `run` を切る。
- トークン・能力の目印・コピーは作るまで番号が分からない。`--label x` を付ければ同じ `run` の後ろの行で `$x` と書ける。
- `say "..."` は記録に1行残す。重要な判断・宣言・「応答なし」を残す。

## ステップごとのチェックリスト（AIの仕事）

スクリプトは何も思い出させない。**自分でこの順に確かめる。** 迷ったら `aid` の補助（下記）で候補を洗い出す。

| ステップ | 確かめること |
|---|---|
| ターン開始 | `turn next` でトラッカーを進める。出てきた「期限切れの付箋」「時期のメモ」を処理する |
| アンタップ | アクティブ・プレイヤーのパーマネントを `untap`（アンタップしない効果に注意）。土地プレイ回数を頭の中で0に戻す |
| アップキープ | `aid triggers --phase beginning.upkeep` で「アップキープの開始時」の誘発を確かめ、あれば `ability` で積んで優先権を回す |
| ドロー | 先手の1ターン目は引かない。それ以外は `draw <席> 1` |
| メイン | 土地は1ターンに1回。唱える手順：コストを決める → マナ能力で `tap`・`mana <席> add` → `mana <席> pay` で支払う → `move <oid> stack`。相手に応答を確かめ、両者パスで解決する |
| 解決 | 効果を文章の順に操作で行う。最後に呪文を行き先へ `move`（パーマネント呪文は戦場、それ以外は墓地。置換効果に注意）。能力の目印は `remove` |
| 解決・効果の直後 | **SBAを確かめる**（ライフ0以下、毒10、タフネス0以下、致死ダメージ、接死、伝説の重複、忠誠0、戦場外のトークン、つける先のないオーラ）。**誘発を確かめる**（ETB・死亡・生け贄・唱えたとき・上陸など）。SBAと誘発が落ち着くまで繰り返してから優先権を渡す |
| 戦闘 | 攻撃クリーチャーを `attack <oid...> --target P2`、タップは別に `tap`（警戒なら不要）。ブロックは `block`。ダメージは自分で計算して `damage`・`life`（先制・二段攻撃・トランプル・接死・絆魂を確かめる）。終わったら `combat-clear` |
| 終了 | 「終了ステップの開始時」の誘発とメモ帳の予定を確かめる |
| クリンナップ | 手札の上限（7枚）を確かめる。`damage clear` でダメージを外す。「ターン終了時まで」の付箋を `note rm` で外す。浮いたマナ・ダイスは各ステップの終わりに `mana <席> clear` |

- **現在のP/T** は印刷値＋カウンター＋付箋から自分で出す。修整は付箋（`note <oid> "+2/+2" --until eot`）に書いて、盤面の表示に常に出しておく。
- **遅延誘発・「次の〜で」** はメモ帳に書く（`memo add "..." --player P1 --at ending.end`）。時期が来ると表示されるだけで、処理は自分で行う。
- **統治者・昼夜・紋章など** はマーカー（`marker`）か統率領域のカードとして置く。
- **オーラ・装備・「これで追放した」カード** は `attach <oid> --to <oid>` で下に重ねる。重ねた先が戦場を離れると重ね置きは外れる（外れたことだけ記録される）。

## 補助（`aid`）

状態を変えず、進行も止めない。**判定ではなくヒント**なので、漏れも誤りもありうる。

- `aid triggers [--phase <フェイズ名>]` … 戦場・統率領域の誘発型能力らしい行
- `aid creatures` … 印刷P/T・カウンター・ダメージ・付箋を並べる（付箋の修整は計算しない）
- `aid check` … ライフ・毒・伝説の重複・つける先のないオーラ・戦場外のトークン・期限切れの付箋・時期のメモ

解決の直後やターンの終わりに `aid check` を一度見ると、見落としに気づきやすい。

## 共通の最小原則

- 状態ファイルのJSONを直接読まず、`show` で見る。ライブラリーの中身は `look`（上から）と `search`（名前順、積み順は伏せる）でしか見ない。
- カードは必要になったものだけ `card <oid か名前>` で全文を読む。同じ文脈では読み直さない。
- マナ・対象・優先権・誘発・SBAは省略しない。乱数はテーブルの `shuffle`・`roll`・`coin`・`pick` で扱い、自分で決めない。
- 分からないルールは推測せず、総合ルールや裁定を調べて根拠を `say` に残す。自作カードの曖昧な点は始める前に確認する。

## モード

- **AI同士**：両席をAIが操作する。`show --hand both` で両方の手札を見てよいが、各席の判断はその席に見える情報だけで行う。
- **対人戦**：ユーザーが優先権を持ちうる所ごとに止めて聞く。AIの席の手札は伏せる（`show --hand <ユーザーの席>`）。
- **一人回し（ゴールドフィッシュ）**：`init --goldfish`。P2 は何もしない相手（ライブラリーなし）。P2のターンは `turn next` で進め、P1に関係する誘発・メモだけ確かめてすぐ P1 のターンへ。リーサルに届いたら `end --winner P1 --reason "..."`、届かずに打ち切るなら `end --winner draw --reason "..."`。自ターン数は結果に自動で記録される。
- `--as P1` を付けると、その席に見えない情報（相手の手札・ライブラリー）を表示・操作できない。

## 決着

`end --winner P1 --reason "決め手" --tag <タグ>` で状態ファイルと同じフォルダの `results.jsonl` に記録する。集計は `stats <results.jsonl> [--tag T]`。
