# 無限コンボの一括記帳

`loop` は検証済みの反復の純増を整数演算でまとめて反映する。カードの組み合わせを自動判定する機能ではない。

1. カード本文を確認し、1周を通常のコマンドで処理して、コスト・対象・誘発・状況起因処理と開始状態への復帰を確認する。
2. 途中の選択や妨害がなく、同じ純増で反復できる区間を決める。対人戦では相手が介入する機会を設け、了承された回数までとする。
3. 有限回数と1周の純増を `loop` で記帳する。検証した1周は回数に重複して含めない。

例：1周でライフ3点が純増することを確認済みなら、追加100万周を次で記帳する。

```text
loop P1 1000000 --life 3 --proof "1周のコストを支払って開始状態に復帰、ライフ+3。反復条件・誘発・SBA確認済み、100万周に合意"
```

`--mana GG` は1周につき緑2点、`--draw 1` は1周につき1枚。マナやライフの消費は差し引いた純増を指定する。純減、途中で敗北や新たな選択が発生する区間、状態が復帰しない区間は通常のコマンドで処理する。スタックが残っている場合やドローがライブラリー残数を超える場合は変更せず拒否する。ドロー内容は秘匿ログに残す。1回の `undo` で全体を戻せる。

トークン生成・展開・タップ・レベルアップ・戦闘は通常のコマンドで記帳する。トークンは必要な有限数を宣言して `token -h` に従い生成する。大量生成をこのコマンドで自動圧縮する機能はない。ドローに伴う誘発や展開判断がある場合は、その判断点までで区切る。
