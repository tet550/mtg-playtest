# 資料の総目次

**初期読み込みは開始に必要な資料だけ。以下を上から全部読まない。**
名前が分かれば直接その資料へ進む。再開時は資料一式でなく、名前付きshow・直近の重要イベント・保留事項を確認する。

## 最初に読む

| 依頼 | 開始用資料 |
|---|---|
| AI同士のBO1・自動対戦 | [軽量対局](ai-vs-ai.md) → [保存先](storage-layout.md)＋[実行中の記録](log-format.md)＋対象デッキの開始方針 |
| 対人戦・盤面ジャッジ | [モード別手順](play-modes.md)の該当モード。対人戦は保存先・記録規約も読む |
| 席分離を明示指定 | [席分離](ai-vs-ai-isolated.md) |
| 実装修正 | 対局は開始しない。[操作の早見表](commands.md)の該当節と変更対象の実装・テスト |

対象デッキの方針は`deck show --brief`／`init`に表示されるパスを使う。
ピザは[開始方針](../../../../decklists/strategy/piza.md)だけを初期読み込みし、コンボ・サイドは下記のタイミングで読む。

## 読み込み方法

小さい開始資料は一度だけ読む。長い参照資料は目次から節を選び、`rg -n '^##' <file>`で位置を確認して該当範囲だけ読む。
BO1でサイド計画を先読みしない。コンボ詳細は成立・回収の判断より前、報告書式は決着後。ただしE/Rの根拠は実行中に記録する。
同じ説明は入口へ複製せず、詳細側を正本とする。目次・移動案内はルール処理を省略してよいという意味ではない。
