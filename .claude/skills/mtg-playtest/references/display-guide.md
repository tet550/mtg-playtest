## 出力フォーマット

`show --ids`の能力タグは、対応する無条件のキーワード単独行から確認できた自身の能力と、明示的な付与だけを表示する。本文のない記録では対応キーワード一覧を使う。`+`はgrant/fx等による付与に限り、自身の能力には付けない。キャッシュの`keywords`には他者への付与やトークン名・キーワード処理も含まれるため、そのまま表示しない。条件付き能力・未対応の表記はタグに出ないので、タグの不在だけで能力なしと判断せず`card show`で確認する。

新規対局の保存先は [storage-layout.md](storage-layout.md) の共通規定に従う。
対戦ログ・報告の項目、根拠参照、訂正、モード別の出力は [log-format.md](log-format.md) に従う。以下は盤面を表示する場合の仕様であり、AI同士の要約に毎回盤面全文を追加する必要はない。

盤面を掲載するときは `mtg.py show` の出力を**そのまま貼る**。手で書き直すと必ずずれるし、
書き直した時点で「Python 側が正本」という前提が崩れる。整形が足りないと感じたら、
出力を手直しするのではなく `mtg.py` の表示側を直すこと。

対人モードでユーザーに見せる1回分は、これだけで足りる（手札も同じ出力に入る）:

```bash
python $M show --hand P1
```


**カードは必ず `[oid]カード名` の形で出る**（手札・戦場・スタック・戦闘のすべて）。
oid を名前の後ろに置くと、直前の P/T やカウンターの数字と地続きに読める
（`兵士 2/2 +1/+1 x1[41]`）ので、前に付ける。
`(T)` はタップ、`(酔)` は召喚酔い、`(token)` はトークン。手札の1列目はマナ総量（土地は `-`）。

**桁揃えする列には日本語を入れない。** 空白による桁揃えは「全角＝ASCII2文字分」を
前提にしているが、表示側のフォントがその通りに描くとは限らず、日本語を挟んだ時点で
そこから右が全部ズレる。日本語を含む列は**必ず行の最後**に置くこと
（手札は `MV` `コスト` を揃えて `[oid]名前 ／ タイプ` を末尾に、
`deck show` は英語名とマナ総量・タイプを揃えて日本語名を末尾に、
戦場はタイプ名を**見出し行**にして桁揃えそのものをやめる）。

戦場は**1パーマネントにつき1行**。タイプごとに見出しを付け、
土地 → クリーチャー → アーティファクト → エンチャント → プレインズウォーカー →
バトル → その他 の順に並べる（アーティファクト・クリーチャーはクリーチャー側に入る）。
**同じ見た目のものは `[127-136]名前 x10` の形にまとめる**（トークンが十数個並ぶと
盤面が読めない）。oid は範囲表記で残るので個体は指せる。1個ずつ見たいときは `show --flat`。

**墓地と追放は oid を出さず、`カード名 xN` にまとめて全部出す。**
末尾数枚だけだと「あの除去されたカードはまだ墓地にいるか」に答えられず、
まとめないと同名が並んで枚数を数えられない。狙って触るとき（対象に取る、
追放する）は oid が要るので `zone P1:graveyard` を使う。

**oid は枚数ではない。** `init` で P1 のカードに 1〜60、P2 に 61〜120 と通し番号を振るので、
P2 のカードは `[61]`〜`[120]` になる。デッキ枚数と読み違えないよう、
説明するときは「oid」と明示するか、`show` の `山札 53` のほうを根拠にすること。
これに、そのターンで何が起きたかを一言添える。

ゲーム終了時は共通規定の結果・所見・検証状態を出す。デッキやカードの評価は根拠がある範囲に限る。

## 運用上の取り決め

- **想定配布範囲**：個人利用。共有する場合は社内のスキル配布手順に従う
- **外部通信**：Scryfall API（`https://api.scryfall.com`）からのカード情報取得と、
  ルール確認のための Web 検索・取得のみ。送信するのは**カード名だけ**で、
  盤面・デッキ・個人情報は一切送らない。`--offline` で通信を止められる
- **スクリプト実行**：あり（`scripts/mtg.py`、`scripts/cardcache.py`、`scripts/decks.py`、`scripts/shuffle.py`。
  いずれも標準ライブラリのみ、書き込み先は `cards/` と状態ファイルのディレクトリに限る）
- **人の判断に委ねること**：ルールの解釈が割れたときの採用判断、自作カードのテキスト確定、
  デッキの採否。スキル側で勝手に確定させず、選択肢を示してユーザーに決めてもらう

### OID表示と人向けターン履歴

`show --ids`はカード名を省略し、P/T・カウンター・タップなどの盤面情報を保持する。
`--hand P1`など既存の可視範囲指定と組み合わせる。名前の確認は通常の`show`へ戻す。
各ターン開始時の名前付き表示は`output/<state名>/turn-starts.md`へ自動保存する。
最初は初手・マリガン後にアンタップ・ステップを進める直前、次ターン以降はアンタップ後・通常ドロー前。
`init --history-hand P1`ならP1の手札も残す。既定none、手札共有のAI戦のみbothを選べる。
undoは復元点と旧記録を無効とする訂正を追記する。
