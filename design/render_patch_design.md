# 描画を作り直さない（差分で当てる）

[web_design.md](web_design.md) の描画の補足。性能のためではなく、**更新で画面の状態を消さない**ための形。

## 前の形と、消えていたもの

更新が届くと `render()` が盤面・手札・スタック・戦闘・Log・操作パネルの要素を全部新しく作り、
`replaceChildren` で入れ替えていた。要素がその都度別物になるので、次のものが消えていた。

| 消えていたもの | 前の手当て（今は無い） |
|---|---|
| 手札のドラッグ（押した・掴んだカードが外れる） | 押している間は描き直しを待つ（`ui.dragging` / `renderPending`） |
| 選んだ文字（Log・カードの文など） | なし |
| 操作パネルの自由入力欄の、打ちかけの文字・フォーカス・IME の変換中 | Enter で足したときだけフォーカスを戻す（`freeFocus`） |
| 開いた折りたたみ（「送った依頼」の `details`） | なし |
| Log のスクロール位置 | 描く前に覚えて戻す（`prevScroll`） |

## 今の形

組み立ての関数（`cardTile`・`playerSide`・`requestBox` など）は前と同じく「その時点の画面の木」を作る。
入れ替える所だけを `patch(parent, children)`（`web/patch.js`）に替え、今の要素に差分で当てる。
同じものと分かる要素は使い回すので、上の状態は更新で消えない。

当てる所: `#top` / `#bottom`（盤面と手札）、`#stack`、`#combat`、`#log`、`#playbody`（操作パネル）、`#thinking`。
カードの詳細（`#detail`）・メニュー・ダイアログはクリックで作るもので、更新では描き直さないので対象外。

A（Preact などの仮想DOMに書き直す）も比べたが、描画の約2,700行の書き直しになる。消えて困るものはどれも
「同じ要素が残っていれば消えない」ので、組み立てはそのままで足りる B（自前の差分）にした。外部のライブラリーは入れない。

## 差分の規則（`web/patch.js`）

- **対応づけ**: `data-key`、無ければ `data-ids`（カード）で同じ親の中の同じものを探す。どちらも無い子は、
  同じ親の中で同じ種類（タグと最初のクラス）が出てくる順で対応づける。タグが違えば作り直す
- **並べ方**: 先に対応を決めて使わない節を外し、使い回す節は並びが変わったときだけ動かす（動かすとフォーカスが外れる）
- **属性**: 新しい木に合わせる。ただし画面の側で付け外しするクラス（`dragging`・`dropover`）と `details` の `open` は残す。
  `style` は CSSOM（`style.cssText`）で書く（サイトの CSP `style-src 'self'` は style 属性の `setAttribute` を止める）
- **イベント**: 組み立てではプロパティ（`el.onclick = …`）で付ける約束で、`on*` を毎回新しい方に付け替える。
  付け替えた関数は新しく作った方の要素を握っているので、自分の要素に触るときは `e.currentTarget` を使う。
  `addEventListener` で付けたものは付け替えられないので、使い回す要素には付けない
- **文字**: テキストの節は中身が違うときだけ書き換える（選んだ文字は、その文字が変わらない限り残る）
- **入力欄**: 組み立てが値を変えたとき（前に入れた値と違うとき）だけ入れる。打ちかけ・変換中の文字はそのまま
- **画像**: `src` が同じなら触らない（読み直し・ちらつきを出さない）

## キーを付けている所

| 要素 | キー | 理由 |
|---|---|---|
| カード | `data-ids` | 並びが変わっても同じカードを使い回す |
| 土地の束・差し込み・開いた束・手札の欄 | 束のキー・上のカードの id・領域・Player | 中のカードと一緒に使い回す |
| スタックの項目・戦闘の列 | 項目の id・攻撃クリーチャーの id | 同上 |
| Log の Batch・Act | Batch の番号・Act の `seq` | 選んだ文字・スクロールを残す |
| 宣言の吹き出し・ライフの増減 | 宣言の `seq`・増減の値 | 新しく出たときだけの CSS の動きを、新しい要素で出す |
| 操作パネルの自由入力欄・組み立ての欄 | `free`・組み立てごとの番号 | 欄を残す。別の組み立てに打ちかけの文字を持ち越さない |

## 合わせて変えた所

- **手札のドラッグ**: イベントは描き直しで消えない `#top` / `#bottom` で受ける（手札の欄は `data-pid` を持つ）。
  ドラッグの間も盤面は更新する。途中の並びは `ui.handOrder` に入れておき、描き直してもその並びで描く
  （確定しなければ掴む前の並びに戻す）。押していたカードが更新で手札から無くなったら、ドラッグはそこで終わる
- **読めなかった画像**: 前は `onerror` で DOM を書き換えていた（マナ・シンボルを文字に、カードの絵を消す）。
  差分で当てると毎回もとに戻されて読み直しになるので、失敗した URL を覚え、組み立ての時点で文字・名前で出す
- **Log の寄せ方**: 今の位置が変わったとき（と開いたとき）だけ、その行へ寄せる。それ以外はスクロールも選んだ文字もそのまま
- **カードの動き（motion.js）**: 場を離れるカードの写しは、描き直しで画面から外れた要素から作るので大きさが測れない
  （前から 0×0 で見えていなかった）。`capture()` で大きさも測っておき、写しはその値で作る

## 気をつけること

- **CSS の動き**: 使い回した要素では、出たときだけの CSS アニメーションはもう一度出ない。出し直したいものはキーを
  変えて新しい要素にする（吹き出し・ライフの増減）。ずっと続く動き（案内の印・考え中の点）は途切れなくなる
- **親をまたぐ移動**: 手札から戦場へ移ったカードは親が違うので、別の要素になる（前と同じ）。動きは motion.js が受け持つ
- **組み立ての費用**: 毎回木を丸ごと作るのは前と同じで、比べる分だけ増える。遅くなったら、そのとき欄ごとに
  「中身が同じなら組み立てない」を足す
